# ВидеоПеревод

Веб-приложение для перевода видео на русский язык: вставляете ссылку — вся
дорожка субтитров переводится целиком и показывается синхронно с видео.
Устанавливается на iPhone/Android как приложение (PWA).

## Возможности

- **Источники**: YouTube (автоматическая загрузка субтитров), прямые ссылки на
  MP4 / WebM / HLS (m3u8), файлы субтитров SRT / VTT, вставленный текстом
  транскрипт с таймкодами.
- **Перевод всей дорожки сразу** с живым прогрессом; при обрыве продолжается с
  места остановки (история хранится в базе).
- **Синхронные субтитры** поверх видео (3 размера, строка оригинала под
  переводом) и **полный транскрипт** с автопрокруткой и переходом по клику.
- **Озвучка перевода** (экспериментально) — системные голоса браузера, оригинал
  приглушается.
- **PWA**: полноэкранный режим без адресной строки, офлайн-заглушка, своя
  кнопка полноэкранного просмотра видео с субтитрами поверх.

## Стек

Next.js 16 (App Router, standalone-выход) · React 19 · TypeScript ·
Tailwind CSS 4 · shadcn/ui · Prisma + SQLite · hls.js · PWA (свой service
worker). Перевод — большая языковая модель через OpenAI-совместимый API.

## Быстрый старт (локально)

Нужен [Bun](https://bun.sh) 1.1+ (или Node.js 20+ с npm/pnpm — команды аналогичны).

```bash
bun install                 # установить зависимости
cp .env.example .env        # переменные окружения
mkdir -p db
bunx prisma db push         # создать базу SQLite + клиент Prisma
bun run dev                 # http://localhost:3000
```

Перед первым переводом создайте файл `.z-ai-config` в корне проекта (см. ниже)
— без него интерфейс работает, но перевод вернёт исходный текст.

### Продакшн

```bash
bun run build   # сборка standalone-сервера (.next/standalone)
bun run start   # запуск на порту 3000 (переменная PORT)
# или на чистом Node:
# DATABASE_URL=file:/абсолютный/путь/db/custom.db node .next/standalone/server.js
```

## Конфигурация

### База данных — `.env`

```
DATABASE_URL=file:../db/custom.db
```

Для продакшна лучше указать **абсолютный** путь (`file:/srv/app/db/custom.db`).
Относительный путь в Prisma разрешается относительно `prisma/schema.prisma`.

### Модель перевода — `.z-ai-config`

SDK читает JSON-файл `.z-ai-config` из корня проекта (не коммитите его — он
уже в `.gitignore`):

```json
{
  "baseUrl": "https://api.z.ai/api/paas/v4",
  "apiKey": "ВАШ_КЛЮЧ",
  "chatId": "",
  "userId": ""
}
```

- `baseUrl` + `apiKey` — реквизиты вашего аккаунта Z.ai (или любого другого
  OpenAI-совместимого провайдера: BigModel, OpenRouter и т.п.).
- Модель по умолчанию — `glm-4-plus`; переопределяется переменной окружения
  `LLM_MODEL`.
- Точка интеграции одна — `src/lib/translate.ts` (функция
  `translateSegments`): чтобы перейти на другого провайдера или SDK, достаточно
  переписать только её.

## Деплой с GitHub

**GitHub Pages не подойдёт** — он раздаёт только статику, а здесь есть сервер:
API-роуты перевода, база истории, обращение к модели. Схема рабочая такая:
код живёт в репозитории, а запускает его один из хостингов, подключённых к
репозиторию (деплой при каждом push):

| Хостинг | Подходит? | Примечания |
| --- | --- | --- |
| VPS (свой сервер) | ✅ лучший | `bun run build && bun run start` за nginx; диск постоянный |
| Railway / Render / Fly.io | ✅ хорошо | нужен том/диск для `db/custom.db` |
| Vercel | ⚠️ частично | serverless: SQLite-файл не переживает редеплой — история будет пропадать; для Vercel переключитесь на Postgres (Neon/Railway) и учтите лимиты длительности функций |
| Netlify | ⚠️ так же | статика + functions, те же ограничения |

Переменные окружения на хостинге: `DATABASE_URL`, при необходимости
`LLM_MODEL` (модель перевода), `PORT` — по требованиям платформы.

## Известные ограничения

- **YouTube может блокировать загрузку субтитров** с IP датацентров
  (бот-защита). С домашнего или небольшого VPS IP обычно работает. Если
  подтянуть субтитры не удалось, приложение само покажет карточку: открыть
  видео → «Показать расшифровку» → скопировать → вставить (таймкоды
  распознаются).
- **Озвучка** использует системные голоса браузера (Web Speech API): русский
  голос должен быть установлен в системе; качество зависит от голоса.
- Встраиваемый YouTube-плеер может не проигрывать отдельные видео
  (ограничение владельца) — перевод, субтитры и транскрипт при этом работают.

## Структура

```
src/
  app/                  страницы и API-роуты (prepare, translate, videos)
  components/app/       формы, плеер, транскрипт, история, PWA-компоненты
  lib/                  субтитры (SRT/VTT/текст), YouTube, перевод, типы
  hooks/                озвучка (Web Speech API)
prisma/schema.prisma    модели Video и Segment
public/                 иконки PWA, manifest, service worker, демо-видео
scripts/                генерация иконок и демо-ролика (Python + ffmpeg)
```

## Полезные команды

```bash
bun run lint          # ESLint
bun run db:push       # применить схему к базе
bun run db:reset      # сбросить базу
python3 scripts/gen_ios_icons.py   # перегенерировать иконки (Pillow)
python3 scripts/make_demo.py       # пересобрать демо-видео (ffmpeg)
```
